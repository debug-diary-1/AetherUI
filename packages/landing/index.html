Getting started

Install and register

Import only the components you use. Each one is a standard custom element, so it works in any framework — or none.

React Vue Angular Svelte Solid Vanilla
npm 
npm install @aetherui-kit/core @aetherui-kit/tokens
usage 
import { defineAeButton } from '@aetherui-kit/core/button';
import '@aetherui-kit/tokens/light.css';

defineAeButton();

Truly headless

Every component is unstyled by default and themed entirely through CSS custom properties and ::part(). No design system to fight.

Accessible by default

WCAG 2.1 AA patterns, full keyboard navigation, focus management, and correct ARIA wiring — verified in Chromium, Firefox, and WebKit.

Typed and tree-shakeable

Per-component subpath exports with generated types, including React 19 JSX definitions. Ship only what you import.

Built for agents

Machine-readable by design

A generated component catalog, JSON schema, and llms.txt let a model generate interfaces without inventing props. @aetherui-kit/agent validates every document before it renders; @aetherui-kit/mcp serves the same contract over MCP.
