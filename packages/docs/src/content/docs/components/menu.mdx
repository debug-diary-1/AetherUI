## Import

```js
import { defineAeMenu, defineAeMenuItem, defineAeMenuDivider } from '@aetherui/core/menu';
defineAeMenu();
defineAeMenuItem();
defineAeMenuDivider();
```

## Menu Item Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `disabled` | `boolean` | `false` | Disabled state |
| `variant` | `'default' \| 'danger'` | `'default'` | Visual variant |

## Menu Item Slots

| Name | Description |
|------|-------------|
| default | Item label |
| `prefix` | Content before label (icon) |
| `suffix` | Content after label |

## Events

| Name | Detail | Description |
|------|--------|-------------|
| `ae-menu-select` | `{ value: string }` | Fired when item selected |

## CSS Parts

| Name | Description |
|------|-------------|
| `base` | Menu container |
| `item` | Menu item |
| `divider` | Divider line |
