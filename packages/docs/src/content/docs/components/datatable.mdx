# DataTable

The DataTable component provides a comprehensive solution for displaying and manipulating tabular data with features like sorting, filtering, pagination, and selection.

<DataTableExample />

## Features

- **Sorting**: Sort data by one or multiple columns
- **Filtering**: Apply global or column-specific filters
- **Pagination**: Break large datasets into manageable pages
- **Selection**: Select single or multiple rows
- **Resizable columns**: Adjust column widths to fit content
- **Custom cell rendering**: Customize how cells are displayed
- **Virtualization**: Efficiently render large datasets
- **Theming**: Customize appearance with CSS custom properties

## Column Configuration

Each column is defined with a `ColumnDef` object that supports the following properties:

```typescript
interface ColumnDef<T> {
  id: string;                                  // Unique column identifier
  field?: keyof T;                             // Data field name to display
  header: string | TemplateResult;             // Column header content
  accessor?: (item: T) => any;                 // Function to extract cell value
  renderer?: (value: any, row: T) => TemplateResult; // Custom cell renderer
  footer?: string | TemplateResult;            // Column footer content
  sortable?: boolean;                          // Enable sorting (true by default)
  filterable?: boolean;                        // Enable filtering (true by default)
  sortFn?: (a: any, b: any) => number;         // Custom sort comparator
  filterFn?: (value: any, filter: string) => boolean; // Custom filter function
  width?: string;                              // Column width (CSS value)
  minWidth?: string;                           // Minimum width (CSS value)
  maxWidth?: string;                           // Maximum width (CSS value)
  align?: 'left' | 'center' | 'right';         // Content alignment
  class?: string;                              // Additional CSS class
  hidden?: boolean;                            // Initially hidden
  resizable?: boolean;                         // Allow column resizing (true by default)
  frozen?: boolean;                            // Pin column to left or right
  format?: (value: any) => string;             // Simple text formatter
}
```

## Properties

| Property | Type | Default | Description |
| -------- | ---- | ------- | ----------- |
| `data` | `array` | `[]` | Array of data objects to display |
| `columns` | `ColumnDef[]` | `[]` | Column definitions |
| `sortable` | `boolean` | `true` | Enable sorting functionality |
| `filterable` | `boolean` | `true` | Enable filtering functionality |
| `selectable` | `boolean` | `false` | Enable row selection |
| `selectionMode` | `'single' \| 'multiple'` | `'multiple'` | Row selection mode |
| `paginated` | `boolean` | `false` | Enable pagination |
| `pageSize` | `number` | `10` | Rows per page when paginated |
| `emptyMessage` | `string` | `'No data to display'` | Message when table is empty |
| `virtualized` | `boolean` | `false` | Use virtualization for large datasets |
| `resizable` | `boolean` | `true` | Allow column resizing |

## Events

| Event | Detail | Description |
| ----- | ------ | ----------- |
| `ae-datatable-sort` | `{ columnId, direction, sortState }` | Fired when sorting changes |
| `ae-datatable-filter` | `{ globalFilter, columnId?, value?, filterState }` | Fired when filtering changes |
| `ae-datatable-select` | `{ selectedRows }` | Fired when row selection changes |
| `ae-datatable-page` | `{ page, paginationState }` | Fired when page changes |
| `ae-datatable-resize` | `{ columnId, width }` | Fired when column is resized |

## Examples

### Custom Cell Rendering

```html
<ae-datatable id="customTable"></ae-datatable>

<script>
  import { html } from 'lit';
  
  const table = document.getElementById('customTable');
  
  // Define columns with custom renderer
  const columns = [
    { id: 'name', field: 'name', header: 'Name' },
    { 
      id: 'status', 
      field: 'status', 
      header: 'Status',
      renderer: (value, row) => {
        const getStatusColor = (status) => {
          switch (status) {
            case 'Active': return 'green';
            case 'Inactive': return 'red';
            case 'Pending': return 'orange';
            default: return 'gray';
          }
        };
        
        return html`
          <span style="color: ${getStatusColor(value)}; font-weight: 500;">
            ${value}
          </span>
        `;
      }
    },
    { 
      id: 'actions', 
      header: 'Actions',
      renderer: (_, row) => html`
        <div style="display: flex; gap: 8px;">
          <button @click=${() => editRow(row.id)}>Edit</button>
          <button @click=${() => deleteRow(row.id)}>Delete</button>
        </div>
      `
    }
  ];
  
  // Set data and columns
  table.data = [
    { id: 1, name: 'John Doe', status: 'Active' },
    { id: 2, name: 'Jane Smith', status: 'Inactive' },
    { id: 3, name: 'Bob Johnson', status: 'Pending' }
  ];
  table.columns = columns;
  
  function editRow(id) {
    console.log(`Editing row ${id}`);
  }
  
  function deleteRow(id) {
    console.log(`Deleting row ${id}`);
  }
</script>
```

### Custom Toolbar and Pagination

```html
<ae-datatable id="advancedTable"></ae-datatable>

<script>
  import { html } from 'lit';
  
  const table = document.getElementById('advancedTable');
  
  // Set up basic properties
  table.data = [...]; // Your data array
  table.columns = [...]; // Your column definitions
  table.sortable = true;
  table.paginated = true;
  table.pageSize = 10;
  
  // Add custom toolbar
  const toolbarSlot = document.createElement('div');
  toolbarSlot.slot = 'toolbar';
  toolbarSlot.innerHTML = `
    <div style="display: flex; justify-content: space-between; width: 100%;">
      <div>
        <button>Export</button>
        <button>Print</button>
      </div>
      <div>
        <input type="text" placeholder="Custom Search..." id="customSearch">
      </div>
    </div>
  `;
  
  table.appendChild(toolbarSlot);
  
  // Add custom search functionality
  document.getElementById('customSearch').addEventListener('input', (e) => {
    table.controller.setGlobalFilter(e.target.value);
  });
</script>
```
