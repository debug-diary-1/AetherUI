# Breadcrumb

A navigation component showing the current page location within a hierarchy.

## Basic Usage

<ComponentExample
  title="Default Breadcrumb"
  description="Basic breadcrumb navigation."
  code={`<ae-breadcrumb>
  <ae-breadcrumb-item href="/">Home</ae-breadcrumb-item>
  <ae-breadcrumb-item href="/products">Products</ae-breadcrumb-item>
  <ae-breadcrumb-item current>Details</ae-breadcrumb-item>
</ae-breadcrumb>`}
/>

## Import

```js
import { defineAeBreadcrumb, defineAeBreadcrumbItem } from '@aetherui/core/breadcrumb';
defineAeBreadcrumb();
defineAeBreadcrumbItem();
```

## Breadcrumb Props

| Name        | Type     | Default | Description         |
| ----------- | -------- | ------- | ------------------- |
| `separator` | `string` | `'/'`   | Separator character |

## Breadcrumb Item Props

| Name      | Type      | Default | Description            |
| --------- | --------- | ------- | ---------------------- |
| `href`    | `string`  | -       | Link URL               |
| `current` | `boolean` | `false` | Current page indicator |

## CSS Parts

### ae-breadcrumb

| Name   | Description       |
| ------ | ----------------- |
| `base` | Container element |
| `list` | The `<ol>` list   |

### ae-breadcrumb-item

| Name        | Description       |
| ----------- | ----------------- |
| `base`      | List item         |
| `link`      | Anchor element    |
| `separator` | Separator element |

## Accessibility

- Uses `<nav>` with `aria-label="Breadcrumb"`
- Current page marked with `aria-current="page"`
- Uses semantic `<ol>` list structure
