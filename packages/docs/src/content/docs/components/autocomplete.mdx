# Autocomplete

The Autocomplete component (`ae-autocomplete`) provides type-ahead suggestions as the user types, supporting both static data arrays and asynchronous data loading.

## Features

- Support for static data passed as an array
- Support for async data fetched via a `loadOptions` callback
- Built-in loading state with spinner
- Configurable debounce/throttle interval to avoid excessive API calls
- Text highlighting for matching portions
- Keyboard navigation and accessibility

## Usage

### Basic Static List

```html
<ae-autocomplete id="countries" placeholder="Type a country name..."></ae-autocomplete>

<script>
  const autocomplete = document.getElementById('countries');
  
  // Pass array of strings
  autocomplete.options = [
    'United States',
    'Canada',
    'United Kingdom',
    'Germany',
    'France',
    'Japan',
    'Brazil',
    'Australia'
  ];
  
  // Listen for selection events
  autocomplete.addEventListener('ae-select', (e) => {
    console.log('Selected:', e.detail.value);
  });
</script>
```

### With Objects

```html
<ae-autocomplete id="colors" placeholder="Select a color..."></ae-autocomplete>

<script>
  const autocomplete = document.getElementById('colors');
  
  // Pass array of objects
  autocomplete.options = [
    { id: 'red', label: 'Red' },
    { id: 'blue', label: 'Blue' },
    { id: 'green', label: 'Green' },
    { id: 'yellow', label: 'Yellow' },
    { id: 'purple', label: 'Purple' }
  ];
</script>
```

### Async Loading

```html
<ae-autocomplete 
  id="search" 
  placeholder="Search..." 
  throttle="400"
></ae-autocomplete>

<script>
  const autocomplete = document.getElementById('search');
  
  // Set async loader
  autocomplete.loadOptions = async (query) => {
    // Only search if query has content
    if (!query) return [];
    
    try {
      // Call your API here
      const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
      const data = await response.json();
      
      // Map to expected format
      return data.results.map(item => ({
        id: item.id,
        label: item.name
      }));
    } catch (error) {
      console.error('Search failed:', error);
      return [];
    }
  };
  
  // Track loading state
  autocomplete.addEventListener('ae-load', () => {
    console.log('Loading started...');
  });
  
  autocomplete.addEventListener('ae-load-end', (e) => {
    console.log(`Found ${e.detail.items.length} results`);
  });
</script>
```

## Properties

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `string[] \| AutoItem[]` | `[]` | Static list of options. Ignored if `loadOptions` supplied. |
| `loadOptions` | `(query: string) => Promise<AutoItem[]>` | `undefined` | Async loader; component renders loading state while pending. |
| `value` | `string` | `''` | Current input value (controlled). |
| `placeholder` | `string` | `''` | Input placeholder. |
| `throttle` | `number` | `200` | Debounce ms before calling `loadOptions`. |
| `disabled` | `boolean` | `false` | Disable interaction. |

Where `AutoItem` is `{ id: string; label: string; disabled?: boolean }`.

## Events

| Event | Detail | Description |
| --- | --- | --- |
| `ae-select` | `{ value: string, item: AutoItem \| null }` | Fired when an item is selected. |
| `ae-input` | `{ value: string }` | Fired on each keystroke (after debounce for async). |
| `ae-load` | `{ query: string }` | Fired before `loadOptions` promise. |
| `ae-load-end` | `{ query: string, items: AutoItem[] }` | Fired after promise resolves/rejects. |

## CSS Parts

| Part | Description |
| --- | --- |
| `input` | Text input field. |
| `overlay` | Positioned wrapper for the popup. |
| `listbox` | Scroll container for suggestions. |
| `option` | Each suggestion option. |
| `spinner` | Loading indicator. |
| `highlight` | Query match highlights. |

## Accessibility

- Input has `role="combobox"` and `aria-autocomplete="list"`.
- Suggestion list has `role="listbox"` with `aria-busy="true"` when loading.
- Suggestions have `role="option"` with proper `aria-selected` and `aria-disabled` attributes.
- Full keyboard support: Arrow keys navigate, Enter selects, Escape closes.
