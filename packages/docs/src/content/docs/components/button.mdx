## Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'primary' \| 'secondary' \| 'ghost'` | `'primary'` | The visual style variant of the button |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | The size of the button |
| `disabled` | `boolean` | `false` | Whether the button is disabled |
| `icon-position` | `'start' \| 'end'` | `'start'` | Position of the icon when both icon and text are present |

## Slots

| Name | Description |
|------|-------------|
| `default` | The button's label text |
| `icon` | Icon content that can be positioned at start or end |

## CSS Parts

| Name | Description |
|------|-------------|
| `base` | The button element |
| `icon` | The icon wrapper element |

| `--ae-color-secondary-hover` | Secondary button hover background color |
| `--ae-color-secondary-foreground` | Secondary button text color |
| `--ae-color-ghost` | Ghost button background color |
| `--ae-color-ghost-hover` | Ghost button hover background color |
| `--ae-color-ghost-foreground` | Ghost button text color |

| `--ae-border-radius` | Button border radius |
| `--ae-font-family` | Button font family |
| `--ae-font-weight` | Button font weight |

## Accessibility

The button component follows WAI-ARIA guidelines:

- Uses native `<button>` element
- Supports keyboard navigation
- Maintains proper focus management with visible focus rings
- Requires aria-labels for icon-only buttons
- Includes proper ARIA attributes when disabled
