# Popover

A floating content panel that appears next to a trigger element.

## Basic Usage

<ComponentExample

## Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `false` | Open state |
| `trigger` | `'click' \| 'hover'` | `'click'` | How to trigger |
| `placement` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'bottom'` | Position |
| `arrow` | `boolean` | `true` | Show arrow |
| `offset` | `number` | `8` | Distance from trigger |
| `close-on-click-outside` | `boolean` | `true` | Close when clicking outside |

## Slots

| Name | Description |
|------|-------------|
| `trigger` | Trigger element |
| default | Popover content |

## Events

| Name | Description |
|------|-------------|
| `ae-popover-open` | Fired when opened |
| `ae-popover-close` | Fired when closed |

## CSS Parts

| Name | Description |
|------|-------------|
| `trigger` | Trigger container |
| `popover` | Popover panel |
| `arrow` | Arrow element |

## Accessibility

- Associates trigger and content
- Keyboard navigable
- Escape key closes popover
