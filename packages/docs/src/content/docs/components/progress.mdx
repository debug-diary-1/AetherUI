
## Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | `0` | Progress value (0-100) |
| `max` | `number` | `100` | Maximum value |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size variant |
| `show-label` | `boolean` | `false` | Show percentage label |
| `indeterminate` | `boolean` | `false` | Indeterminate mode |

## CSS Parts

| Name | Description |
|------|-------------|
| `base` | Base wrapper |
| `track` | Background track |
| `bar` | Progress bar |
| `label` | Percentage label |

## Accessibility

- Uses `role="progressbar"` 
- Sets `aria-valuenow`, `aria-valuemin`, `aria-valuemax`
- Screen reader announces progress updates
