## Installation

You can install AetherUI using your preferred package manager:

<Tabs>
  <TabItem label="pnpm">```bash pnpm add @aetherui/core ```</TabItem>
  <TabItem label="npm">```bash npm install @aetherui/core ```</TabItem>
  <TabItem label="yarn">```bash yarn add @aetherui/core ```</TabItem>
</Tabs>

## Usage

After installation, import and define the components you want to use:

```js
import { defineAeButton } from '@aetherui/core';

// Define the component
defineAeButton();

// Use it in your HTML
<ae-button>Click me!</ae-button>;
```

## Using CSS Tokens

Import the default theme CSS file:

```js
import '@aetherui/tokens/light.css';
// Or for dark theme
import '@aetherui/tokens/dark.css';
```
