## Overview

Aether UI is built with Web Components, making it compatible with any JavaScript framework. We provide official adapters for popular frameworks to enhance the developer experience and ensure proper TypeScript support.

## Using the Adapters Package

Our `@aetherui/adapters` package provides framework-specific bindings:

```bash
pnpm add @aetherui/adapters
```

## Framework-Specific Setup

### React

React components are available in the `/react` subpath:

```jsx
import { AeButton } from '@aetherui/adapters/react';

function App() {
  return (
    <AeButton variant="primary" onClick={() => alert('Clicked!')}>
      Click me
    </AeButton>
  );
}
```

### Vue

Vue components can be imported from the `/vue` subpath:

```vue
<script setup>
import { AeButton } from '@aetherui/adapters/vue';

function handleClick() {
  alert('Clicked!');
}
</script>

<template>
  <AeButton variant="primary" @click="handleClick">
    Click me
  </AeButton>
</template>
```

### Angular

Angular components are available through the `AetherUIModule`:

```typescript
// app.module.ts
import { AetherUIModule } from '@aetherui/adapters/angular';

@NgModule({
  imports: [
    BrowserModule,
    AetherUIModule
  ],
  declarations: [AppComponent],
  bootstrap: [AppComponent]
})
export class AppModule { }
```

```typescript
// app.component.ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  template: `
    <ae-button variant="primary" (click)="handleClick()">
      Click me
    </ae-button>
  `
})
export class AppComponent {
  handleClick() {
    alert('Clicked!');
  }
}
```

### Svelte

Svelte components can be imported from the `/svelte` subpath:

```svelte
<script>
import { AeButton } from '@aetherui/adapters/svelte';

function handleClick() {
  alert('Clicked!');
}
</script>

<AeButton variant="primary" on:click={handleClick}>
  Click me
</AeButton>
```

## TypeScript Support

All framework adapters include TypeScript definitions out of the box. You'll get proper type checking and autocompletion in your IDE.
