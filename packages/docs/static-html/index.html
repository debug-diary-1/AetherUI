Components

AetherUI offers a growing collection of UI components built with web standards. Each component is designed to be accessible, customizable, and framework-agnostic.

Accordion

Expandable content sections that can be toggled open or closed.

Alert

Notification messages that provide feedback to user actions.

Autocomplete

Text input with suggestion filtering for quick entry.

Button

Interactive controls for forms and user interaction.

Checkbox

Selection control that allows multiple options to be chosen.

Combo

Combination of text input and dropdown for flexible selection.

DataTable

Interactive table for displaying and manipulating tabular data.

Dropdown

Menu that appears below a button to show additional options.

Modal

Dialog overlay that focuses user attention on important content.

Radio

Selection control that allows only one option to be chosen.

Tabs

Tabbed interface for organizing content into separate views.

TreeView

Hierarchical display of nested items with expand/collapse functionality.

Features

AetherUI is built with modern web standards and best practices.

🔄

Framework-Agnostic

Use with any framework or no framework at all. Built on Web Components, compatible everywhere.

🎨

Customizable

Headless design that allows complete styling control through CSS custom properties.

♿

Accessible

Built with accessibility in mind, following WAI-ARIA patterns and keyboard navigation.

📦

Modular

Import only what you need. Each component can be used independently.

⚡

Lightweight

Optimized for performance with minimal dependencies.

📝

TypeScript

Full TypeScript support with type definitions for enhanced developer experience.
