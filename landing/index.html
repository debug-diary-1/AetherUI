Headless Web Components for Modern UIs

A framework-agnostic UI library built with Web Components and Lit. Accessible, lightweight, and fully customizable.

Get Started Browse Components

Framework Agnostic

Works seamlessly with React, Vue, Angular, Svelte, or vanilla JavaScript. Use your favorite tools without compromise.

Headless & Themeable

Style components your way using CSS custom properties and shadow parts. Complete freedom for your design system.

Accessible by Default

Every component follows WAI-ARIA patterns and is thoroughly tested for accessibility. No compromises.

Lightweight & Fast

Core bundle under 15KB gzipped. No dependencies, no bloat, just what you need to build incredible user experiences.

TypeScript First

Accurate types and excellent IDE integration. Enjoy auto-completion, type checking, and better developer experience.

Framework Adapters

Optimized bindings for React, Vue, Angular, and Svelte. Get the best of both worlds with framework-specific wrappers.

Simple to Use, Hard to Outgrow

Install, import, define, and use. That's all it takes to get started with AetherUI components. Progressively enhance your application with modern UI primitives.

Learn More 
// Install
npm install @aetherui/core

// Import
import { defineAeButton, defineAeDialog } from '@aetherui/core';

// Define once
defineAeButton();
defineAeDialog();

// Use in your HTML
<ae-button onClick="dialog.show()">Open Dialog</ae-button>

<ae-dialog id="dialog">
  <span slot="title">Welcome!</span>
  <div slot="content">
    Your dialog content here.
  </div>
</ae-dialog>
